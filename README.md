## 💡 使用技巧

### Composer 快捷键
| 操作 | 快捷键 |
|:----|:------|
| 内联编辑 | Ctrl/Cmd + I |
| 独立窗口 | Ctrl/Cmd + Shift + I |
| Agent模式 | Composer中切换 |

### Agent 模式能做的
- 自动创建/修改多文件
- 运行终端命令
- 分析项目结构
- 自动修复错误

## ⚙️ 配置规则

项目根目录创建 `.cursor/rules/` 文件夹添加自定义规则。

详见 [cursor-config-templates](https://github.com/lyb4533580/cursor-config-templates) 仓库。

## 🔧 工作流优化

### 项目级 .cursorrules

```markdown
# 告诉 Cursor 你的项目技术栈和编码规范
```
